TRIGGER

GitHub Actions schedule

.github/workflows/daily.yml

A cron trigger fires a fresh Ubuntu VM every day. It checks out the repo, installs Python/ffmpeg/Playwright, and runs the whole pipeline below in one shot — no server of your own to maintain.

1 · INGEST

Pull today's raw news

ingest.py · sources.yaml

Fetches every RSS feed in parallel, tags each item with its source's trust tier, and dedupes exact-URL repeats. Dead feeds fail gracefully and get skipped.

2 · VERIFY

Decide what's trustworthy

verify.py

Clusters duplicate coverage of the same event, classifies each story's category, hard-rejects rumour/clickbait language, and ranks by editorial priority to pick exactly 3 stories.

3 · IMAGES

Find real, on-topic pictures

images.py · companies.yaml

Tries the article's own image first, then the subject company's homepage hero, then their logo, then a generated panel — always the company the story is about, not the outlet reporting it.

4 · WRITE

Turn facts into a readable brief

summarize.py · Anthropic API

Rewrites press-release language into plain third-person news copy: an 8-word headline, up to 3 facts, and one "why it matters" line. Falls back to a rule-based writer if no API key is set.

5 · RENDER

Build the actual slides

render_carousel.py · render_video.py

Jinja2 templates + a headless Chromium browser screenshot each of the 6 slides to JPEG. A separate step narrates and assembles a vertical video with text-to-speech and ffmpeg.

6 · APPROVE

Human in the loop, always

approval.py · Telegram Bot API

Sends the full preview and a Publish/Discard button straight to your phone, then polls Telegram for up to 2 hours. Nothing below this step runs unless you tap Publish.

7 · HOST

Make images fetchable by URL

assets.py · GitHub Releases

Instagram's API fetches media from a public URL rather than accepting uploads directly — so the 6 JPEGs get pushed to a GitHub Release first, giving each one a public link.

8 · PUBLISH

Go live

publish_instagram.py

Two-step Graph API dance: create a carousel container from the hosted image URLs, then publish it. YouTube's equivalent step exists in code but isn't connected yet.
